# 0002 · 语言强相关题不删除，改为「语言梗」标签默认禁用

最初需求是「去掉所有与语言强相关的谜面」。决定**不物理删除**：谜底依赖特定语言文字/发音/拼写/符号的题（假名双关、五十音图、数字串、化学式、谐音字谜等）打「语言梗」风味标签，默认全链路隐藏、不进任何抽取池，仅在新开局的风味筛选中显式勾选才出现（AND 语义）。

理由：用户只精通中文时确实玩不了这些题（默认禁用满足原诉求），但删除是不可逆的——这些题是采集清洗证据链的一部分，题数口径（2042）牵动 README、site-guard 下限检查与历轮体检记录；打标签把「不可玩」变成可逆的过滤器配置。代价是每轮体检要持续记得这类题「禁用但存在」。

判定标准：谜底依赖特定语言的文字、发音、拼写或符号系统，换成任何其他语言即不成立；仅「故事发生在国外/有外国人名」不算。
