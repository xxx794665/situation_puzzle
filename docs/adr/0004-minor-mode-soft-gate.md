# 0004 · 未成年模式：开启免密、关闭需密码，密码硬编码在前端配置

常规儿童保护是「开启随意、关闭要密码」；本项目的密码**硬编码在公开仓库的前端配置文件 `js/config.js` 里**（查看源代码即可见），挡不住会看源码的人。

这是用户明确选择的取舍：**可恢复性优先于强度**。纯静态站没有服务端鉴权可言，这本来就是软门闩；硬编码的好处是忘记密码时翻配置就能找回，不需要任何找回流程。配套规则：开启免密（含首访游玩前的一次性提示）；关闭需密码；被挡标签（红汤+黄汤）隐藏不可解，不留一键解锁口子。多人房是另一层级：房主建房时配置、房规全房生效、服务端拦截选汤（见 `worker/src/room.js`），密码机制不适用于房间。
