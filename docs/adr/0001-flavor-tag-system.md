# 0001 · 风味标签独立成 flavor 字段，不并入题材 cats

题库已有自由生长的题材标签 `cats`（脑洞/悬疑/都市…，采集自源站，941 道落在「其他」）。新增的内容口径标签（本格/变格、清汤/红汤、王八汤/黄汤/语言梗）**另立独立字段 `flavor`**：两组互斥项每题必选其一（本格或变格、清汤或红汤），三个可选项按内容叠加。

理由：风味标签的用途是**过滤控制**（未成年模式挡红汤+黄汤、语言梗默认禁用、三处入口的筛选器），必须是受控词表、全量覆盖、结构可校验；`cats` 是采集属性，允许长尾和缺失。混放会污染题材筛选 UI 与统计口径，也无法表达「本格/变格互斥」这类约束。

后果：精品层与汤库两层、前端与 Worker 端题库都要带 `flavor`；2042 题需一次性打标（AI 批量判定 + 人工复核，判定表留 `tools/` 作证据链）；后续新增题必须补全 flavor 否则被校验拦下。
