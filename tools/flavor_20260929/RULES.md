# 七风味标签判定标准 · 2026-09-29

判定单位：每题以 truth（汤底）为主、surface（汤面）为辅。

## 互斥组1：本格 / 变格（每题恰好一个）

- **变格**：汤底里有任何真实发生的非现实元素——鬼魂/灵异真实存在、超能力、魔法、诅咒真实生效、时间旅行、外星人、科幻未来设定、变身、平行世界等。
- **本格**：汤底发生的一切都能用现实逻辑解释。汤面看似灵异但汤底揭示是人为/误会/巧合 → 本格。判汤底，不判汤面。

## 互斥组2：清汤 / 红汤（每题恰好一个）

- **红汤**：汤面或汤底包含——他杀、自杀、意外致死（坠亡、溺死、冻死、饿死、中毒身亡、车祸致死等）、尸体、血腥、肢解、恐怖惊吓（灵异氛围、诡异、细思恐极）、虐待。
- **清汤**：以上都没有。只有悲伤、离别、误会、轻伤 → 清汤。

### 口径变更（2026-09-29，用户裁定）

> 若为自然死亡、善终，则不应判断为红汤。

- **自然死亡（善终、老死、病故）、以及仅为背景设定的「已故」（人物自然离世、不参与情节冲突）→ 清汤**。
- 例：亡妻/亡父/亡友是背景设定或善终 → 清汤；同样的人是被杀/自杀/惨死 → 红汤。
- 其余红汤判据（他杀/自杀/意外死/血腥/恐怖惊吓/虐待）不变。

## 可选项

- **王八汤**：汤底滑稽、荒诞、脑筋急转弯式（答案让人哭笑不得而非后怕）。黑色幽默/以死亡为笑点不算。
- **黄汤**：汤面或汤底含性行为、性描写、性犯罪、色情内容。
- **语言梗**：谜底依赖特定语言的文字/发音/拼写/符号系统（谐音、字谜、拆字、文字双关、假名/五十音、颜文字、数字串、化学式、英文拼写、回文）。判法：把整题翻译成英语，谜底还能成立吗？不能成立 → 语言梗。仅「故事发生在外国、有外国人名」不算。

## 流程

1. `make_batches.js` 切 21 批 → 21 路判定子代理逐批读题打标，输出 `out/batch_NN.jsonl`（含一句话理由）。
2. 合并校验（merge 脚本）：2042 题全覆盖、互斥约束成立。
3. 复核：口径变更（善终不算红汤）后，对已判批次中「红汤且理由仅涉自然死亡/背景性已故」的题做定向复核（`out_fix/`），合并时以复核结果覆盖。
4. `apply_flavor_tags.js` 回写母本与精品层 → 重跑构建 → `--check` 幂等自检。
