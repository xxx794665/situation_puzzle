# 移动端走查审计结论（2026-09-29）

方法：桌面 Chromium IAB 模拟 7 档视口 × 6 屏（首页/单人/随机/汤库/房厅/房间），程序化布局审计
（横向溢出 / fixed 遮挡 / 触控目标 / 文字截断 / 小字号 / 三列结构 / 段落行宽）+ 39 张截图存证。
房间测试连线上 Worker（房号 PQGGED，身份固定重连验证通过）。
模拟环境限制：pointer:coarse / hover:none / 软键盘 / 安全区不可模拟，归真机清单。

## 分级问题清单

### P0（影响使用）
1. **弹窗外壳「透明拦截」中间态**：`.modal-wrap` 打开/关闭路径存在长时间滞留态
   （display:flex + opacity:0 + pointer-events:auto，全屏）。两次复现：首访未成年弹窗、
   进房昵称弹窗。真实用户表现为「什么都点不动但看不到任何弹窗」。
   修法：壳默认 display:none；打开立即 opacity>0；关闭立即回 display:none。
2. **房间聊天浮层遮挡核心控件**（房间期间全局钉住、跨屏跟随、含自动重连场景）：
   - 360×740：完全盖住「离开房间」「我准备好了」（44px 全遮挡）
   - 390×844：盖住单人局「提问输入框」（308×16）
   - 834×1112：盖住「问答记录」「猜底手账」按钮与聊天输入（44~49px）
   - 1024/1180：盖住「随机一锅/下一锅/AI 汤主设置/我要猜汤底/放弃/问答记录/猜底手账」
   新访客默认 hidden（✓），问题在有房间会话时出现。修法方向：非房间屏自动收起；
   展开时内容区让位（padding-bottom）或改抽屉；收起药丸避开关键控件落点。

### P1（明显难受）
3. **顶栏不吸顶**：下滚后随机模式/汤库/多人房间/音乐台全部不可达；汤库 1942 题长列表尤甚。
4. **触控目标低于 44px 热区**（README 声称 ≤860 档 ≥44px，实测不符）：
   筛选 chips 34px（随机/汤库/房间选汤三处）、未成年模式（全房）34px、
   换成 AI 汤主 32px、dock-btn 32px（≥1024）、聊天输入/发送 35px（≥1024）、
   清空 27px（≥1024）、房间聊天药丸 20px、音量滑条 8px（≤1024）/ **4px（≥1024）**。
5. **「放弃」按钮文字被裁**（.giveup-btn scrollWidth>clientWidth，390~1366 全档，含桌面回归）。
6. **大屏单列拉伸（Q4 数据）**：段落宽 834 竖屏 775px（约 48 字/行）、1024 横屏 933px（58 字）、
   1180 横屏 **1105px（约 70 字）**；1366 三列中间列 735px 正常。
   → 建议不新增平板档，先给正文列限宽（max-width ~40em 居中）即可救 834/1024/1180 三档。

### P2（打磨）
7. 小字号：10.5px（题材/风味小标签、「我」徽章、「汤主不看这里」）、11px（筛选组标签/清空/副标题）。
8. modal-wrap 悬空中间态的防御 CSS（同 P0-1 的副产品）。
9. 汤库来源 chip「Jed's List」截断（疑似 ellipsis 设计，真机确认）。

## 正面结论
- 全部 7 档 × 6 屏 **零横向溢出**（docSW ≤ 视口宽）。
- 1366 三列桌面布局**零回归**（左问答 / 中汤桌 / 右备忘录正常并排）。
- 844×390 横屏矮档：≤520px 高度档生效，数字上无异常。
- 功能链路全通：首访弹窗→未成年模式、提问判定、随机模式、汤库、建房/进房/固定身份重连。
- 新访客无聊天浮层（默认 hidden ✓）、首访弹窗只出现一次（✓）。

## 真机清单（模拟测不了）
- pointer:coarse 省电档：SoupFx.stats() 应回显 lite:true（模拟里恒为 false）
- 软键盘推挤：提问输入聚焦时对话区收缩、聊天浮层收起（README 已有 heuristic）
- 刘海/手势条安全区（viewport-fit=cover）
- iOS Safari 实际滑动流畅度、120Hz 发热（省电档实测）
- PWA 添加到主屏幕 + 图标 + 独立窗口
- 微信内置浏览器能玩（best-effort）
